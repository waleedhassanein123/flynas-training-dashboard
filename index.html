Deploying to Render (dashboard.render.com)

Render provides free, fast, and fully automated hosting with automated HTTPS/SSL encryption. Because our flynas Executive Dashboard is engineered as a zero-dependency static application (`index.html`), deploying takes less than 3 minutes using either **GitHub connection** or **Render CLI**.

1

Method A: Continuous Deployment via GitHub (Recommended)

Automatic Updates
Step 1: Save Dashboard File

Create a local folder on your computer named flynas-dashboard. Save your main code file inside it as index.html.

Step 2: Push to GitHub Repository

Go to GitHub.com, create a new public or private repository named flynas-training-dashboard, and push your index.html file to the main branch.

Step 3: Connect dashboard.render.com

Log in to dashboard.render.com. Click the blue "New +" button in the top right and select "Static Site".

Step 4: Configure Site Settings

Select your flynas-training-dashboard repo and fill in the form fields exactly as shown below:

Setting Field Value to Enter Notes
Name flynas-training-dashboard Determines your default URL address
Branch main Branch containing your index.html file
Root Directory (Leave Blank) Defaults to the repository root
Build Command (Leave Blank) No compilation needed for pure static HTML/JS
Publish Directory . Serves files from root directory
2

Method B: Direct Terminal / CLI Deployment

If you prefer deploying directly from your terminal using Render's blueprint format, create a render.yaml file in your directory: 

services:
  - type: web
    name: flynas-training-dashboard
    env: static
    buildCommand: ""
    staticPublishPath: .
    routes:
      - type: rewrite
        source: /*
        destination: /index.html
Custom Subdomain Setup

To link a corporate domain like dashboard.flynas.com:

  1. In dashboard.render.com, click your static site service.
  2. Navigate to Settings → Custom Domains.
  3. Click "Add Custom Domain" and type your domain name.
  4. Add a CNAME record in your DNS provider pointing to flynas-training-dashboard.onrender.com.
Security & Access Control

Ensure executive data confidentiality with these Render features:

  • Automatic SSL: TLS/SSL certificates are auto-provisioned free of charge.
  • IP Headers: Render adds standard headers for proxying behind Cloudflare or corporate VPNs.
  • HTTP Headers: Customize security headers via render.yaml or Render Settings.
